# Chapter 05: LLM evaluation

Evaluation of structured drought-impact extraction quality on a manually annotated event-level dataset. Thesis tables and figures are reproduced from frozen annotations/metrics (no article bodies required).

## What this does

1. Loads frozen `evaluation_set.json`, `model_metrics.json`, and `posthoc.json`.
2. Restricts post-hoc reviews to the nine shared articles via `src/restrict_posthoc.py` (writes `posthoc_restricted.json`).
3. Computes dataset counts, severity / recency / impact plots, performance tables, and post-hoc aggregates via `notebooks/report_chapter5.ipynb`.
4. Writes thesis outputs under `results/figures/` and `results/tables/`.
5. Optional tools (`label_dataset.py`, `run_models.py`) support re-labelling or live re-runs when the private corpus and API keys are available.

## Layout

```text
05_llm_evaluation/
  data/
    evaluation_set.json   # 65 articles, 33 events (annotations)
    model_metrics.json    # event-level P/R/F1 per model
    posthoc.json          # full post-hoc impact + attribute archive
    posthoc_restricted.json  # nine shared articles (generated)
  notebooks/
    report_chapter5.ipynb # ALL calculations, displays, and exports
  src/
    restrict_posthoc.py   # filter post-hoc reviews to nine shared articles
    label_dataset.py      # Streamlit labeller (optional)
    run_models.py         # API runner (optional; needs keys + private corpus)
  results/                # written by the notebook
    figures/
    tables/
```

## How to run

Open and run **all cells** in `notebooks/report_chapter5.ipynb`.

No API keys or newspaper article bodies are needed for this path. The notebook:

1. Loads the three JSON files under `data/`
2. Computes dataset counts and plots severity / recency / impact
3. Builds the performance table from `model_metrics.json` (and checks F1 = 2PR/(P+R))
4. Restricts post-hoc labels to the nine shared articles (`src/restrict_posthoc.py`) and writes impact/attribute tables
5. Writes outputs under `results/figures/` and `results/tables/`

Regenerate post-hoc tables without the notebook:

```bash
python chapters/05_llm_evaluation/src/restrict_posthoc.py
```

Both post-hoc tables use the same nine articles (rows for `NEWS_2018_011316` and `NEWS_2020_018637` are dropped). Usable-location counts reconstruct the published spatial filter by subtracting potato-article location TPs; they are not a re-filter of place names. The full manual archive stays in `data/posthoc.json`.

Optional tools (not required to reproduce thesis tables):

```bash
streamlit run chapters/05_llm_evaluation/src/label_dataset.py
python chapters/05_llm_evaluation/src/run_models.py --model "gemini/gemini-3.5-flash"
```

Defaults (overridable via env / CLI): schema from Chapter 04 `schemas.py`; source corpus `chapters/04_database_construction/data/preprocessed/all_articles_deduplicated.json`. Env overrides: `EVAL_BUILDER_LLM_SCHEMA`, `EVAL_BUILDER_SOURCE_JSON`, `EVAL_BUILDER_OUTPUT_DIR`, `DROUGHT_MONOREPO_ROOT`. Full article dumps from `run_models.py` go under `data/runs/` (gitignored).

## Reproducibility and limits

- Newspaper article bodies are **not** included. Only annotations and metrics are frozen here.
- Event-level TP/FP/FN matching was done offline; `model_metrics.json` stores the resulting scores (the notebook verifies F1 from stored P and R).
- There is **no live LLM API** in the Chapter 05 robustness suite (Chapter 04 covers extraction).

Offline checks:

```text
python reproducibility_and_robustness_testing/chapter_05_llm_evaluation/run_evaluation_report.py
python reproducibility_and_robustness_testing/chapter_05_llm_evaluation/run_src_smoke.py
python reproducibility_and_robustness_testing/chapter_05_llm_evaluation/run_labeller_smoke.py
```

| Check | What it tests | Why |
| --- | --- | --- |
| `run_evaluation_report.py` | Frozen JSON + F1 consistency + golden CSV match | Thesis tables stay reproducible offline |
| `run_src_smoke.py` | Script import + Chapter 04 schema / `llmn_extraction` wiring | Optional tools still resolve without calling providers |
| `run_labeller_smoke.py` | Launch Streamlit UI → health OK → shut down | Annotation UI still starts (synthetic fixture; no full corpus) |
